# Toplantı Tutanakları

Sanal ofisin karar toplantıları (`toplanti` kısayolu → `/oksis-toplanti` usulü). Her toplantı
bir dosya: `YYYY-MM-DD-<konu>.md`. Kararın son sözü Faruk'tadır; onaylanan karar
[[SESSION-HANDOFF]] panosuna "aktif dilim" olarak geçer. Organizasyon: [[oksis-sanal-ofis-organizasyon]].

Bu klasör VS Code çalışma alanında "Toplantı Odası" adıyla açılır ve Pixel Agents'ta
Ürün & Alan odasına (toplantı masası + kanepe köşesi) bağlıdır.
