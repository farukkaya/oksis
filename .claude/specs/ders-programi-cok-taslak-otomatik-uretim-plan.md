# Ders Programı — Çok-Taslak Modeli + Otomatik Üretim (Header Akışı) Implementasyon Planı

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development` (önerilen) veya `superpowers:executing-plans` ile görev-görev uygula. Adımlar checkbox (`- [ ]`) ile takip edilir. Her görevden önce ilgili güncel dosyayı **oku** (kod parçaları hedef bağlamı gösterir, tam dosya değil).

**Goal:** Otomatik Üretim'i sınıf-bağımsız, header'dan tetiklenen, sıfırdan üretip yeni Taslak yaratan bir akışa taşımak; ve programı "sınıf+dönemde tek Yayında + çok Taslak" modeline geçirmek.

**Architecture:** Clean Architecture + CQRS (.NET 10, EF Core 10) backend (`oksis-api`) + React/Vite/TS frontend (`oksis-web`) + workspace dokümanları (`oksis`). İki parça: **A** = program tekillik modeli + publish-swap (temel); **B** = otomatik üretim header akışı (A'ya bağlı). **C** = dokümanlar.

**Tech Stack:** MediatR, FluentValidation, EF Core (fluent config + migrations), xUnit; React Query, Zustand, vitest, i18next.

**Bağlayıcı tasarım:** `.claude/specs/ders-programi-cok-taslak-otomatik-uretim-design.md` (K1..K7).

**Çalışma dizinleri:** backend görevleri `oksis-api/`, frontend `oksis-web/`, doküman `oksis/`. Commit'ler OKSİS formatı: `YYYY-MM-DD <type>: Türkçe özet.` (bugün 2026-06-15). Branch: `dersprog`.
