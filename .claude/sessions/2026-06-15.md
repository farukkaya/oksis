## Goal
Complete Faz 2 of the Timetable (Ders Programı) module — the only remaining gap was **Faz 2.6: notification + SignalR fan-out** for the 5 timetable domain events.

## Key discovery
The notification infrastructure described in CLAUDE.md (Outbox, dispatcher, channels) did **not exist in code** — only an isolated email-only Invitation flow. So Faz 2.6 required building a general (non-silo) in-app notification core first. Confirmed against the `Oksis_Ders_Programi_*.docx` source analyses (user-provided) and the binding spec; Teknik Analiz §10 requires only event→Hangfire (not a transactional Outbox), which justified deferring Outbox as Debt-N1.
