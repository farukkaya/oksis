## Teyit edilen kök neden

Tatil Takvimi'nde üç ayrı kaynak, üçü de aktif sezondan kopuk:
1. **Alt başlık** `data.ts:23` → düz sabit string `'2025–2026 sezonunun...'`.
2. **`year`** `HolidaysTab.tsx:215` → `new Date().getFullYear()` (takvim yılı, sezon değil); `holidays?year=` ve "Sezon Özeti {year}" buradan.
3. **Topbar** doğru aktif sezonu (`useCurrentSessionQuery`) gösterir ama tab kullanmıyor.

**Asıl mesele:** Backend tatilleri `AcademicSessionId` ile **sezona bağlı** tutar; create aktif sezonu `ICurrentSessionProvider`'dan atar; `GetHolidaysQuery(year, seasonId)` `seasonId` ile gerçek sezon-scope yapabilir. **FE `seasonId` göndermiyor** → yazma sezona, okuma takvim yılına göre. Şimdilik aktif sezon (2025-2026) takvim yılıyla (2026) çakıştığı için gizli; sezon ıraksayınca patlıyor (orijinal bulgu: topbar 2029-2030).

**Kapsam dışı (ayrı):** Akademik Takvim zaten `isCurrent` sezona pinli (AcademicCalendarPage:29) → A1.2'nin "takvim pinli" kısmı tamam. Settings tatillerinin takvimde işaretlenmesi = #12/B3.1. `holidays` çağrısının proxy yerine :5112'ye gitmesi = R4.5.

## Kararlar (kullanıcı, 2026-06-26)
- **D1:** Sorgu **seasonId-bazlı** (aktif sezon id'si gönderilir; year ekseni bırakılır).
- **D2:** Tab **daima aktif/current sezonu** yönetir; **topbar seçicisi sürmez** (settings global).

## Uygulama adımları (FE ağırlıklı — backend değişmez)

1. **Aktif sezon kaynağı:** `HolidaysTab` → `useCurrentSessionQuery()` (CurrentSessionDto: `id, name, startDate, endDate, isCurrent, status`).
2. **useHolidays seasonId'ye geçer:**
   - `school-settings.queries.ts:175` `useHolidays(year = new Date().getFullYear())` → `useHolidays(seasonId: string | undefined)`; `enabled: !!seasonId`; istek `/school-settings/holidays?seasonId=${seasonId}` (year gönderilmez).
   - `school-settings.keys.ts:7` `holidays: (year)` → `holidays: (seasonId)` (tenant prefix korunur).
3. **HolidaysTab year referanslarını kaldır:**
   - `:215` `const year = new Date().getFullYear()` → `const session = useCurrentSessionQuery().data; const seasonId = session?.id`.
   - `:414` "Sezon Özeti {year} tatil dağılımı" → `{session?.name}` ("2025–2026").
   - Tatil Listesi başlığı/boş-durum aktif sezon adını gösterir.
4. **Mutation'lar seasonId'ye:** `school-settings.mutations.ts` create/update/delete variables `year` → `seasonId`; invalidate `schoolSettingsKeys.holidays(seasonId)`. (Create backend'de zaten aktif sezona yazıyor; sadece FE invalidate ekseni düzelir.)
5. **Alt başlık (data.ts:23):** sabit "2025–2026" kaldırılır → sezon-agnostik metin ("Sezonun ders yapılmayan günleri — Akademik Takvim, Yoklama ve Ders Programı bu listeyi kullanır."). Sezon adı zaten "Sezon Özeti" kartında dinamik gösterilecek (sub'ı PageTop'a plumb etmeye gerek yok).
6. **Aktif sezon yoksa:** boş/yönlendirme durumu ("Aktif sezon bulunamadı") — useCurrentSessionQuery null/Active değil ise.
