## ISSUE-04 — Parent-Student Relationships (commit `Issue #4 …`)
- **Domain:** new `ParentStudentRelationship` AR (`Create`/`UpdatePermissions`/`Revoke`) + `ParentStudentLinkedEvent`/`ParentStudentRevokedEvent`. Invariants: no self-relation, `ValidUntil >= ValidFrom`. `IsActive => RevokedAt == null`.
- **Persistence:** `users.parent_student_relationships` table + filtered unique index `ux_parent_student_active` (active-pair uniqueness) + check constraints; migration `20260530153113_…`. DbSet added to `IApplicationDbContext`/`OksisDbContext`.
- **API (`RelationshipsController`, base `api/v1/users`):** `GET students/{id}/parents`, `GET parents/{id}/students` (active only, joined names/student number), `POST relationships`, `PUT relationships/{id}`, `DELETE relationships/{id}` = revoke (audit-preserving, not hard delete). GET → `users.view-detail`, writes → `users.update` (no new perms).
- **Codes:** `USERS_RELATION_SELF` (400), `USERS_RELATION_*_PROFILE_REQUIRED` (409), `USERS_RELATION_DUPLICATE` (409), `USERS_RELATION_NOT_FOUND` (404). Extended `ResultExtensions` mapping.
- **Bug found+fixed during tests:** revoking a *future-dated* relationship set `ValidUntil`=today < `ValidFrom` → violated check constraint. Fixed `Revoke` to clamp end date to `ValidFrom`.
- **Tests:** Domain 165 (+7), Application 469 (+15), Api 70, Tests 22, Integration 67 (+3). All green.
- **Deviations (completion_status):** "≥1 primary contact per active student" invariant deferred; `RelationType` kept at 4 values; revoke clamp; GET lists active only.
