**Tarih:** 2026-06-26 · **Kalem:** Ayarlar bug-temizleme planı B0.2H · **Efor:** L
**Karar:** Option A — mevcut `CurriculumHourTemplate` (MEB master) + `SchoolWeeklyHourOverride`
(okul/sezon katmanı) + `RequiredHoursResolver` modeline bağlanır. **Yeni
`SubjectGradeLevel.WeeklyHours` kolonu EKLENMEZ** (3. çelişkili kaynak olur).

## Keşif bulguları (doğrulanmış — kod üzerinden)

### Backend (mevcut, hazır)
- **`CurriculumHourTemplate`** (`master.curriculum_hour_templates`, `MasterEntity`,
  tenant-agnostik): `EducationLevel, GradeLevelCode("5".."12"), SubjectId, WeeklyHours(1–40),
  IsElective, MebDecision, Version`. Unique `(Version, GradeLevelCode, SubjectId)`.
  Aktif sürüm `CurriculumVersions.Active = "2025.04"`.
  **Seed: 5–12 TÜM seviyeler** (demo, her seviye ~30 sa — `CurriculumHourSeedData.cs`,
  migration `20260614_curriculum_seed_grades_5_12`). NOT: teachers dokümanı "yalnız 5"
  diyor ama güncel değil; gerçek seed 5–12. (Gerçek MEB seti hâlâ follow-up Debt.)
- **`SchoolWeeklyHourOverride`** (`academics.school_weekly_hour_overrides`, `TenantEntity`):
  `AcademicSessionId, GradeLevelCode, SubjectId, WeeklyHours(0–40), Reason?`. Unique
  `(SchoolId, AcademicSessionId, GradeLevelCode, SubjectId) WHERE is_deleted=0`.
  **Yazma yolu YOK (spec S-6)** — sadece `Create` factory var, `Update` yok. Resolver okur.
- **`IRequiredHoursResolver` / `RequiredHoursResolver`**: `(sessionId, codes[]) → {code: totalHours}`.
  Katmanlar override > master, seviye TOPLAMI döndürür (per-subject DEĞİL).
- **`GradeLevel`** (`master.grade_levels`, master): `Code("0".."12"), Name, DisplayOrder,
  EducationLevel`. 13 seviye seed.
- **`Subject`** (`master.subjects`, master, **global**): saat alanı YOK/dönmüyor.
  `subject_grade_levels` M2M (gradeLevelIds) bağlı — dersin verildiği seviyeler.
  `SubjectDto`: `..., GradeLevelIds, Description, HasAssignments` (saat yok).
- **`GetRequiredTotalHoursQuery`** + `CurriculumHoursController`
  (`GET /api/v1/curriculum-hours/required-total?sessionId=&gradeLevelCode=`,
  izin `curriculum-hours.view`) — yalnız seviye TOPLAMI; per-subject editör için yetersiz.
- İzin `curriculum-hours.view` VAR; `curriculum-hours.override`/`.import-template` **yok**
  (teachers/permissions.md:24 — "tam Müfredat Saati modülünde eklenecek", ertelendi).

### Dilim 1 — Backend domain + write yolu (TDD)
1. **`SchoolWeeklyHourOverride.UpdateHours(int weeklyHours, string? reason)`** ekle
   (0–40 doğrulama, reason trim/null). Domain testi.
2. **İzin `curriculum-hours.override`** ekle: `PermissionCatalog`/seed + RolePermission
   (SchoolAdmin tam; SuperAdmin yok/okuma yok — yazma okul-admin; Teacher yok) + migration.
   `permission-matrix.md` güncelle.
3. **`SetSubjectWeeklyHoursCommand`** (bulk, tek transaction):
   - İmza: `(Guid SubjectId, Guid? SessionId, IReadOnlyList<Item> Items)`,
     `Item = (string GradeLevelCode, int WeeklyHours)`.
   - SessionId null → aktif sezon (`IsCurrent`); sezon yoksa Conflict.
   - Validator: Subject var+aktif; her GradeLevelCode geçerli `GradeLevel.Code` **ve**
     dersin atanmış seviyelerinden (`subject_grade_levels`) biri; WeeklyHours 0–40.
   - **Reconcile (full-set, gönderilen satırlar için):** master template değeri (aktif
     sürüm) ile karşılaştır → eşitse override'ı **sil** (varsa; resolver master'a düşer);
     farklıysa **upsert** (`UpdateHours` veya `Create`). Tenant+sezon scope.
   - İzin: `curriculum-hours.override`.
   - Application testleri: create-override, update-override, equals-master→delete,
     unknown-subject/invalid-level/level-not-in-subject reject, session default.
4. **`GetSubjectWeeklyHoursQuery(Guid SubjectId, Guid? SessionId)`** →
   `SubjectWeeklyHoursDto { Guid SubjectId, Guid SessionId, string Version,
   IReadOnlyList<Row> Rows }`,
   `Row = (string GradeLevelCode, string GradeLevelName, EducationLevel,
   int? MebHours, int? SchoolHours, int EffectiveHours, bool HasOverride)`.
   - Dersin `subject_grade_levels` seviyeleri için satır üret (GradeLevel.DisplayOrder
     sıralı); master (aktif sürüm) + override join; effective = override ?? meb ?? 0.
   - İzin `curriculum-hours.view`. N+1'siz EF projection. Query testi (master-only,
     override-üstün, master-yok→meb null effective 0).
5. **`GetCatalogWeeklyHoursQuery(Guid? SessionId)`** (liste kolonu için batch) →
   `IReadOnlyList<CatalogHoursDto { Guid SubjectId, int? MinHours, int? MaxHours }>`
   (effective min–max; saat yok → null). Tek sorguda templates+overrides+subject_grade_levels.
   İzin `curriculum-hours.view`. Query testi.
6. **API:** `CurriculumHoursController`'a ekle:
   - `GET /api/v1/curriculum-hours/subject/{subjectId}?sessionId=` (view)
   - `GET /api/v1/curriculum-hours/catalog?sessionId=` (view)
   - `PUT /api/v1/curriculum-hours/subject/{subjectId}` body `{sessionId?, items[]}` (override)
   `dotnet build` + `dotnet test` yeşil + `dotnet format`.

## Açık/teknik notlar
- **Sezon kapsamı:** override şema gereği sezon-scoped (`AcademicSessionId NOT NULL`).
  A1.2 kararı "topbar seçici settings'i sürmez" ile uyumlu: saat **aktif sezona** pinlenir
  (holidays deseni), topbar seçicisinden bağımsız.
- **Master yok → effective 0:** bir seviyede master template yoksa (yeni/seed'siz ders)
  MEB "—", okul override girilebilir; effective override ?? 0.
- **Reconcile yeri backend'de:** FE tüm satırları gönderir; backend eşit→sil / farklı→upsert.
  Override tablosu temiz kalır (resolver mantığıyla tutarlı).
- **Cache:** resolver Redis kullanmıyor (doğrudan EF). Yeni query'ler de cache'siz başlar
  (veri küçük) — invalidate-before-commit riski (option C) bu dilimde doğmaz.
