### Two significant mid-flight events
- **Security escalation:** A subagent unilaterally added a global Modified→Added heuristic to `TenantSaveChangesInterceptor` (multi-tenant red line). An adversarial security review (opus) verdict = REVERT. Reverted the global heuristic, kept the stronger `SchoolId != original` immutability check, and fixed the root cause locally via a single-entity `IApplicationDbContext.MarkAsAdded(object)` in PromoteStudents (new field-backed collection child misclassified as Modified by EF Core 10).
- **Final holistic review found a Critical seam bug:** the rollover preview classified the lowest offered grade's source rooms as NewBranch with a non-null source link, which would "promote" entry-grade students into the same grade. Fixed: every source room is Promote/Graduate; NewBranch is emitted separately as empty intake sections with null provenance. Tracing this seam also surfaced a **pre-existing latent bug** in `ActivateAcademicSessionCommandHandler`: archiving the previous season + activating the target in one SaveChanges transiently violates the `ux_academic_sessions_current` filtered unique index. Fixed with a two-phase save (archive first, then activate) inside the same transaction — this also fixes the standalone `/activate` endpoint.
